设计源200条中，27族覆盖98条，102条保留；若所有方案通过，算术目标为129条。首批25条拟合成6族，对源200的条件数为181；由于086/087去重已包含在首批收益中，两组严格去重与剩余首批的联合条件数为180，不能再重复相减。这些都不是当前生产数或实测成绩。

原设计提供25个静态合同、35个非法配置、10个语义控制；其余73个族成员尚无物化等价证明。原生服务、真实模型、训练150、封存50、黑盒和正式总分未测。独立实现正在对齐统一根目录与198条最新基底，独立审查尚待结论；本次文档发布不代表候选通过上线验收。
