# 检索第一阶段：兼容198条的文本视图支持

本次仅发布根检索器的可选retrieval_views支持及合成不变式测试。生产RUNBOOK_ITEMS仍198条，没有加入六族或180条候选，没有修改matcher/system/aggregates、固定执行器、评分器、服务、数据和封存集。新语义实现仍需独立复审与原生验证。

文本视图只有id、after_id、description、examples、description_repeat；不能放API、SQL、参数、默认值或答案。活动模板的执行合同仍在原模板中。文本视图独立进入原BM25、覆盖门禁和top-k，最后映射到活动模板并去重，不补位。没有按题号或完整问题查SQL/答案，不增加隐藏执行模板。description_repeat仅无损表达相同短文档的原重复次数；本轮400文档语料及全部统计均与198基线相同。

独立检查517条冻结输入×4种top-k：198原路径2068次逐字段不变；隔离180候选2068次与198结果按能力族归并全等。合并范围公开词面50/50、未合并350/350、已见正常控制25/25。它们是检索能力代理，不是答题正确率、未见泛化或模型分数。517条包含已公开模板和作者合成文本，完整冻结材料仅本地留存，本公开摘要不等于异机全量复现实验。

隔离组合保留最小别名054→052与087→F14，重复别名和显式视图必须同owner且逐份文字相等，只索引一次。原补丁会忽略首视图的after_id，独立检查发现缺失/自循环也被接受；集成补充了最终位置校验，所有声明锚点必须存在且位于视图之前。18类非法元数据控制通过，正向语料、排序、得分和旧198路径保持不变。后续检索线程应以本提交的新源哈希继续，不以旧补丁覆盖该校验。

本机交错3轮每版1551次retrieve：新198 P95/P99约1.090/1.209ms，隔离180约1.093/1.230ms、max1.597ms；含tracemalloc的索引构建约15ms，增量Python分配约0.81MB。不包含模型/API、输入对象和全进程RSS，不宣称正式环境资源认证或端到端提速。隔离库单条紧凑JSON最大2450字节；dict/list深度最大7，官方深度计数未明确，不作正式合规结论。

第一阶段只包括保守400文档回放。六张概念卡、语义信息提取、子意图多路召回、多样性排序均未在本次启用。180的参数语义和实际得分仍是独立门禁，不能因召回恢复切换生产。
