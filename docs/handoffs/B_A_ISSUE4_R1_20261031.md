1. 先核公开manifest及各源码外层pin，再导入；新公开闭包与原验收来源明确区分。只加载声明typed表，可信全schema的成功零人口建0行表，不造_empty；失败/缺schema/截页返回失败，不能变成功空。

3. B负责真实请求、逐页HTTP/schema来源、raw原行/total、capture与身份账本；这些元数据断言本身不认证原生或原子快照。主包与consumer/地址/容量/管理协议不同，按各自合同装载，不把一种收据套给另一种。
4. B负责真实typed loader、SQL保护、最终envelope/URL的UTF-8字节、wire 4KB及官方depth。静态模板或本地compact长度通过不能替代最终封装；不关漂移门禁，不截长参数，不自动改官方执行器。
5. full_eip_objects_binding_complete/business_complete/full_original_question_certified/full_answer_certified等未通过标记保留false。all_ties、known_only、源单位和details_population按显式合同执行；参考冲突与缺权威关系单列。
