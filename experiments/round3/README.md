## 真实模型结果

用户本轮最终批准“先20题试一下”，沿用已提出的每题一次、最多60次实际HTTP请求（含重试），本轮额度已结束，不继续使用剩余7次请求。安全加载本机 `.env.local` 到进程，未执行其 shell 内容，未保存认证头、密钥或完整模型 prompt/响应；TLS证书和主机名校验开启。

`run_model_baseline.py` 包装原 `quick_eval.main(['20'])` 和原 `evaluate_case()`，只收集结果、候选及HTTP用量。传输守卫在每次尝试前检查上限，SDK重试也计数，连续3次网络/HTTP失败中止；硬停止穿透业务异常回退。连接失败也占用名额，因此记数是实际已发HTTP数的保守上界。本次53次全部返回200。零网络守卫检查覆盖上限、错误目标和连续故障，3项通过。

11个条件共2,442次检索，逐条排名、候选ID/原分数/tier/coverage、标签集合外候选数、top2间隔、最佳标签内外分差、recall@3/@5、耗时均见 `retrieval.csv`；分层聚合见 `retrieval_summary.json`。基线12条改写漏召的是 `CMDB-001` 的改写。4条库外意图在全部条件下都存在候选，尚未运行这些控制的模型弃权验证。

回归原文移除探针中，回归34题仅2题仍召回关联标签、top1为1题；开发166题仍全部召回。大量模板同时失去两份几乎重复的检索文本，不能把它误称为真实未见准确率，但说明需要有独立语义描述，不能用原文命中代替泛化证据。

17组原参考查询和固定模板均经原执行器、原评分函数复核，答案比较均得5分。前12组对应预先固定控制，另5组来自模型低分题，是事后定位检查。固定模板采用已核实的原默认参数，未把模板 SQL 换成参考 SQL；这是能力诊断，不是自动填参成绩。比较时 elapsed固定为0以单独核查答案，实际冷执行器缓存耗时另存，不冒充模型时延成绩。

4条实体控制从同表、满足其他原条件的记录中确定性选另一个实体，替换问题和参考API条件，再由原执行器重算答案；均未复用旧答案。其中1条重算后答案恰与旧答案相同，仍记录为相等而非宣称答案有变化。自一致评分只证明生成产物可被原评分器消费，不能循环论证真实模型正确。

本机一次无费用测量：基线索引约2.11ms，基线各子集P95最大约1.55ms、单次最大约1.77ms；离线进程峰值RSS约257MiB，含原执行器，不含数据服务子进程。Mac本地诊断不能证明正式2GB/CPU/统一环境合规。

**决策：保留根生产实现与200模板。** 词汇屏蔽在原文上的top1增加，没有在改写上体现召回/排名改善，资源词屏蔽还丢召回；无完整链路候选版本对照，不落盘删词或合并模板。
