- 根目录和 B 的模板、检索器逐文件 SHA-256 相同：200 条模板，检索器为已接入的 A `1928514`。这次 A 新增的是验收材料，不需要再次复制业务代码。

- 记录实际前一步的记录数、依赖字段可用数、声明步号与执行器实际步号，以及 HTTP / JSON 读取失败。只允许本地 8080 数据服务，模型入口禁止调用，外部网络尝试为 0。

```bash

  --output reports/a_handoff_review_new.json
```
