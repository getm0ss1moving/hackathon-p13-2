# CMDB 模型背景知识（最小集）

> **表名映射规则**：SQL 中使用 `CLOUD_xxx` / `SYS_xxx` 原始表名，API URL 与文档中使用脱敏名：`CLOUD_xxx → xxx`，`SYS_xxx → S_xxx`。

## 一、公共属性

以下属性为所有 CI 表继承的公共字段，每张表均有，不再逐一列出：

| 属性标识 | 类型 | 说明 |
|----------|------|------|
| `id` | uuid | 记录主键 |
| `resId` | uuid | 资源内部唯一标识，对外查询依据 |
| `nativeId` | string | 上游系统原始ID |
| `name` | string | 资源显示名称 |
| `status` | string | 资源状态 |
| `logicalRegionName` | string | 逻辑区域名称（常用查询条件） |
| `azoneName` | string | 可用区名称 |
| `tenantName` | string | 所属租户名称 |
| `vdcName` | string | 所属VDC名称 |
| `createdAt` | long | 创建时间 |
| `class_Name` | string | CI类型标识 |

## 三、CI 关系

> 仅列出涉及表之间的关联关系，可用于 SQL JOIN。

| 源 CI | 目标 CI | 关系语义 | 基数 | 关联字段 |
|-------|---------|----------|------|----------|
| `ApplicationModuleIns` | `ApplicationModule` | 应用组件属于应用服务 | 多对一 | `appModuleId` |
| `ApplicationModule` | `Application` | 应用服务属于应用 | 多对一 | `appId` |
| `NET_NODE` | `VM_NOVA` | 虚拟网元节点 - 虚拟机 | 多对一 | `refVmId` |
| `NET_NODE` | `S_X86Server` | 虚拟网元节点 - 服务器 | 多对一 | `refServerId` |
| `PORT` | `NETWORK` | 网卡属于网络标签 | 多对一 | `networkId` |
| `VOLUME` | `VM_NOVA` | 云硬盘挂载于虚拟机 | 多对多 | `-` |
| `PORT` | `SUBNET` | 网卡属于子网 | 多对多 | `-` |
| `PORT` | `SECURITY_GROUP` | 网卡属于安全组 | 多对多 | `-` |
| `VFW` | `PORT` | 虚拟防火墙使用网卡 | 多对多 | `-` |
| `VFW` | `ROUTER` | 虚拟防火墙使用虚拟私有云 | 多对多 | `-` |
| `CLUSTER` | `HOST` | 主机组包含宿主机 | 多对多 | `-` |
| `CLUSTER` | `VM_NOVA` | 主机组属于虚拟机 | 一对多 | `clusterId` |
| `HOST` | `VM_NOVA` | 宿主机虚拟化虚拟机 | 一对多 | `hostId` |
| `VM_NOVA` | `FLAVOR` | 虚拟机使用规格 | 多对一 | `flavorId` |
| `VM_NOVA` | `IMAGE` | 虚拟机使用镜像 | 多对一 | `imageId` |
| `VM_NOVA` | `PORT` | 虚拟机 - 网卡 | 一对多 | `devId` |
| `S_X86Server` | `BMS_NODE` | 服务器关联裸金属服务器节点 | 一对一 | `physicalServerId` |
| `LISTENER` | `VM_NOVA` | 监听器使用虚拟机 | 多对多 | `-` |
